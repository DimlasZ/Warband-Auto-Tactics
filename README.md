# Warband Auto Tactics

Downloads for **Warband Auto Tactics**, a 5v5 autobattler (Windows, closed alpha).

This repository only holds the game's releases. There is no source code here.

## Install

1. Open the [latest release](https://github.com/DimlasZ/Warband-Auto-Tactics/releases/latest).
2. Download `WarbandAutoTactics-win-Setup.exe` and run it.
3. Windows may show "Windows protected your PC", because the game is not code-signed yet.
   Click **More info → Run anyway**.

The game installs for your Windows user (no admin rights needed) and adds a desktop and Start menu shortcut.

## Updates

The game updates itself. When a new version is out, the main menu offers it: click **Update** and the
game restarts on the new version. Your runs, achievements and settings are kept.

## Uninstall

Windows Settings → Apps → Installed apps → Warband Auto Tactics → Uninstall.
